ProxiSpeak --- Geospatial Virtual Office Collaboration Platform
Project Overview
ProxiSpeak is a browser-based virtual office collaboration platform
designed to make remote teamwork more interactive. It provides a shared
office-style environment where teammates can connect and communicate
within a common digital workspace.

The project combines an office interface with communication features
such as office chat, personal chat, online presence, and notifications.
Its goal is to make remote collaboration feel more connected by bringing
teammates into a shared virtual office experience.
Problem Statement
Remote teams often use separate tools for messaging and collaboration,
which can make everyday interaction feel disconnected. ProxiSpeak
explores a shared virtual office where team members can interact and
communicate in one online workspace.
Objectives
- Create a shared virtual office environment for remote teams.
- Support team-wide and direct communication.
- Represent teammate presence in the workspace.
- Provide notifications for relevant communication activity.
- Combine the frontend and backend into one application.
- Explore a more interactive approach to remote collaboration.
Key Features
- Virtual Office Interface: An office-style scene that serves as
  the shared workspace.
- Office Chat: A conversation space for team-wide communication.
- Personal Chat: Direct messaging between users.
- Online Presence and People Discovery: Features for viewing or
  finding teammates in the workspace.
- Notifications: In-app notifications for messages and relevant
  activity.
- Proximity-Oriented Collaboration: A virtual-office concept
  centered on interaction between nearby teammates.
- Camera and Screen Sharing: Media collaboration capabilities
  where supported by the current application build.
Feature availability should be verified against the running application
before being presented as fully functional.
