# ProxiSpeak — Geospatial Proximity Audio Ecosystem

## About the Project
ProxiSpeak is a virtual office application that allows users to move around a shared 2D map and communicate through voice chat based on their proximity to one another.

## Main Features
- Interactive virtual office map
- Real-time user movement
- Proximity-based voice communication
- Voice volume adjustment based on distance
- Real-time communication between users

## Technologies
- Frontend: React, HTML5 Canvas, Web Audio API
- Backend: Node.js, Express.js, Socket.IO
- Database: MongoDB
- Audio communication: WebRTC
